# Queflow

動的優先度スコアリングと4つのタスクキュー（突発・日付固定・繰り返し・プロジェクト先頭）を備えた、単一ファイル完結型のタスク管理ツールです[cite: 1]。

## アーキテクチャ・技術仕様
- **構成**: 単一ファイル完結型（`index.html` 内に CSS / HTML / Vanilla JS を集約）[cite: 1, 2]
- **動作環境**: モダンブラウザ（ビルドツール・外部ライブラリ・サーバー不要）
- **データ永続化・スキーマ**: ブラウザの `localStorage` を使用（v1.2 スキーマ採用。v1.0/v1.1 形式のJSONバックアップからの自動マイグレーションに対応）[cite: 1]

## 実装済みのコア機能（4ビュー構成）

1. **⚡ 今日の実行キュー (`#view-today`)**[cite: 1]
   - **クイック登録バー**: 突発（Spot）と日付固定（Scheduled）を切り替えて即座に登録[cite: 1]
   - **セクションA: 突発・単発タスク (Spot)**: 未完了を全件表示[cite: 1]
   - **セクションB: 日付固定タスク (Scheduled)**: 実行指定日が到来したタスクを表示（指定日待ち一覧の開閉表示対応）[cite: 1]
   - **セクションC: 今日の繰り返しタスク (Routines)**: 周期条件に合致したタスクを表示[cite: 1]
   - **セクションD: プロジェクト別・先頭キュー (Project Heads)**: 各プロジェクトの未完了先頭タスクを動的優先度スコア順に表示[cite: 1]
2. **📊 プロジェクト見通し (`#view-forecast`)**[cite: 1]
   - **動的優先度スコア算出**: `最終優先度 ＝ (基本優先度 × 100) ＋ 期限余裕日数`（数値が小さいほど上位に自動配置）[cite: 1]
   - 週間投入時間と目標期限に基づく完了日シミュレーション、およびクローズ済みプロジェクトの表示切替[cite: 1]
3. **📋 WBS・繰り返し管理 (`#view-wbs`)**[cite: 1]
   - **プロジェクトWBS管理**: タスクの順序入替、テキスト一括追加（細分化）、選択タスクの一括クローズ・完了・未着手戻し[cite: 1]
   - **繰り返しタスク設定・管理**: 3方式（完了日からN日後 / 毎週〇曜日 / 毎月〇日）の周期設定および停止（クローズ）管理[cite: 1]
4. **📥 WBSインポート・移行 (`#view-import`)**[cite: 1]
   - CSVファイルおよびExcel/スプレッドシートからのタブ区切りペーストによる一括取込（ライブプレビュー機能付き）[cite: 1]
   - JSON形式での完全バックアップ・復元、全タスクCSVエクスポート、デモデータ再読込・初期化[cite: 1]

## 開発・保守ルール（AIアシスタントおよび開発者向け）

本プロジェクトはコア機能の実装が完了しており、現在は**ピンポイントな機能改善およびバグフィックスのフェーズ**にあります。ソースコードを変更する際は、以下のルールを厳守してください。

### 1. 変更範囲の厳格な制限
- **指示された箇所のみを修正する**: 依頼されていない箇所のリファクタリング、CSS変数・クラス名の変更、既存DOMのID変更、フォーマットの自動整形は禁止します。
- **単一ファイル構成の維持**: `index.html` からCSSやJSを別ファイルへ分割しないでください[cite: 1, 2]。
- **データ互換性の維持**: `localStorage` のデータ構造（v1.2 スキーマ）および `importJsonBackup` のマイグレーション処理[cite: 1]を破壊しないよう注意してください。

### 2. 事前確認プロセス（コード出力前の合意）
ソースコードを修正・出力する前に、必ず以下のステップを踏んでください。
1. **現状の把握と原因の特定**: 対象となるHTML要素（`#view-*` 等）やJS関数（`renderAll`, `switchTab` 等）の現在の挙動を簡潔に説明する[cite: 1]。
2. **修正方針の提示**: 「どの部分のコードを」「どのように変更するか（追加・削除・書き換えの概要）」を提示する。
3. **影響範囲の確認**: 他のビューやレンダリング処理、データ保存処理に悪影響が出ないかを明記する。
4. **ユーザーの承認待ち**: **ユーザーから「進めてください」等の承認を得るまで、修正後のコードや差分は出力しない。**
